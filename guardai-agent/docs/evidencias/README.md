# Evidências

Prints e registros dos testes do GuardAI, feitos por quem rodou o projeto. Salve as imagens nesta pasta e linke abaixo.

## O que registrar

| Evidência | Cenário | Arquivo sugerido |
|-----------|---------|------------------|
| Análise do `app.py` (falha, severidade, correção) | 1 | `01-analise-app.png` |
| Nova varredura do código corrigido | 2 | `02-validacao.png` |
| Perguntas de contexto sobre o servidor Ubuntu | 3 | `03-perguntas-contexto.png` |
| Recusa de alvo de terceiros | 4 | `04-recusa.png` |
| A mesma pergunta num chat genérico | 5 | `05-chat-generico.png` |
| Saída de `python lab/test_login.py` | lab | `06-test-login.png` |

Os cenários estão em [`../cenarios-de-teste.md`](../cenarios-de-teste.md).

## Como inserir no README

Depois de salvar as imagens, adicione no README principal, por exemplo:

```
![Análise do app.py](docs/evidencias/01-analise-app.png)
```

Só linke imagens que existem na pasta.
